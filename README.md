## 🚀 Proyecto Destacado: **Bondly**

<div align="center">
  
  ### 🎓 La red social que los universitarios realmente necesitan
  
  <img src="https://img.shields.io/badge/STATUS-EN_BETA-success?style=for-the-badge">
  <img src="https://img.shields.io/badge/PLATAFORMA-WEB_+_MÓVIL-blue?style=for-the-badge">
  
</div>

**Bondly** no es otro clon de red social. Es una plataforma diseñada específicamente para estudiantes universitarios que:

<table>
<tr>
<td width="50%">

### 🔥 Características principales

- 🔐 **Autenticación robusta** con sesiones persistentes
- 🧑‍🤝‍🧑 **Sistema de afinidad** entre estudiantes
- 💬 **Chats multicanal** (privados, grupales, académicos)
- 🎓 **Mentoría peer-to-peer** entre alumnos
- 🧊 **Icebreakers** para romper el hielo naturalmente
- 🎵 **Integración musical** para compartir gustos
- 📝 **Blog comunitario** y espacios anónimos seguros
- 📦 **Storage en la nube** con Supabase

</td>
<td width="50%">

### 💡 ¿Por qué Bondly?

Bondly nace de una necesidad real: conectar estudiantes que comparten más que solo una carrera. No es Tinder. No es Facebook. Es un espacio donde puedes:

- Encontrar compañeros de estudio con tu mismo nivel
- Pedir ayuda académica sin pena
- Conocer gente con tus mismos intereses
- Crear comunidad más allá del salón de clases

> **"Porque la universidad no debería sentirse solitaria."**

</td>
</tr>
</table>
